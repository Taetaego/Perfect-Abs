# 규칙 상세 (평소 기록할 때는 읽지 않는다)

`CLAUDE.md`의 요약 규칙을 자세히 적은 문서다. 진행률 바·이월은 `scripts/diet.py`가 이 규칙대로 계산한다.

## 진행률 바 규칙
- **남은 양**: 표 대신 코드블록 안의 텍스트 진행률 바로 보여준다(모바일 가독성용). 항목마다 3줄: 1줄째 `이모지 항목명  섭취 / 목표 단위`, 2줄째 바, 3줄째 `퍼센트 · 남음 N단위`(넘었으면 `퍼센트 · 초과 N단위`, 단위는 kcal 또는 g). 퍼센트는 항상 쓴다. 바는 목표 100% = █ 12칸이고 목표 미만이면 나머지를 ░로 채운다. 100% 이상이면 █를 12칸보다 길게 이어 붙여(1칸 = 목표의 1/12, 반올림, 최대 24칸) 넘은 만큼 길어지게 한다. 항목 사이는 빈 줄. 이모지는 🔥칼로리 🍚탄수화물 🍗단백질 🥑지방. 기준은 칼로리, 탄수화물, 단백질, 지방 기준이고 (순섭취 목표 10/21부터 1,600 kcal·지 55g·탄 100g, 이전은 1,750·65g·130g / 단 170g / 탄은 + 운동 소모분/8, 상한 250g)와 남은 양. 운동한 날은 먹어도 되는 총량 = 그날 목표(1,600) + 운동 소모 kcal

## 초과분 이월 규칙
- 전날까지 순섭취가 목표(1,750 + 운동 소모 반영 전 기준)를 넘긴 초과분은 `data/log.json`의 날짜별 합계에서 매번 계산해, 다음 날 칼로리 목표에서 **하루 최대 300 kcal씩** 차감하고 남은 초과분은 계속 이월한다. (예: 10/2 초과 811 → 10/3 목표 1,450, 10/4 1,450, 10/5 1,539)
- 단백질 170g은 줄이지 않는다(지방은 10/21부터 55g). 탄수화물은 칼로리 차감분만큼 자연스럽게 줄여 안내한다.
- 목표보다 덜 먹은 날의 "남음"은 이월하지 않는다. 초과분만 이월한다.
- 이월 누적 = max(0, 전날 누적 + (그날 순섭취 − 그날 기본 목표)). 오늘 목표 = 그날 기본 목표 − min(300, 전날까지 누적). 기본 목표는 10/20까지 1,750, 10/21부터 1,600(`diet_core.GOAL_STEPS`). 모두 `data/log.json`에서 계산한다.
- 진행률 바 4줄 아래 같은 코드블록에 항상 두 줄만 붙인다. 간단하게 쓰고 다른 설명은 덧붙이지 않는다.
```
⚠️ 초과  517kcal
📦 누적  943kcal  (초과 517 + 쌓인 것 426)
```
  - `초과` = 오늘 순섭취 − 오늘 칼로리 목표(0 미만이면 0). `쌓인 것` = 어제까지 누적 − min(300, 어제까지 누적) (오늘 목표에서 미리 갚기로 깎은 만큼을 뺀 나머지). `누적` = 초과 + 쌓인 것. 오늘 목표를 덜 먹은 날은 그 절약분만큼 쌓인 것에서 빼고 0 미만이면 0.
- **당일(진행 중)에는 아직 안 먹은 절약분을 미리 빼지 않는다.** 표시 누적 = 쌓인 것(어제까지 누적 − min(300, 어제까지 누적)) + 오늘 초과. 절약분 차감은 하루가 끝난 뒤(다음 날 첫 기록 시점)에만 반영한다. (예: 어제까지 누적 674, 오늘 목표 1,450 → 오늘 아직 초과 0이어도 누적 374로 표시)
- **답변 본문(다음 조언 포함)에서 이월·상환·내일 목표 변화를 말로 설명하지 않는다.** 이월은 코드블록의 `초과`·`누적` 두 줄로만 보여준다.
- 이월은 하루가 끝났을 때(다음 날 첫 기록 시점) 그날의 최종 초과분으로 확정한다. 당일은 아직 진행 중이라 초과분이 바뀔 수 있다.
- 이월 시작: 2026-10-02부터. 10/2 초과분은 594 kcal (운동 소모 915 kcal 반영, 순섭취 2,344). 이후 10/2 기록이 추가되면 달라진다.

## Diet 페이지 (GitHub Pages)
- `site/index.html`이 모바일용 대시보드(일간·주간·월간·추이)다. 화면 순서는 칼로리(1순위) → 단백질(2순위) → 탄수화물 → 지방이고, 채팅 응답과 같은 3줄 형식(항목·수치 / 바 / 퍼센트·남음)을 쓴다. 글자는 크고 대비는 높게 유지한다. 디자인은 "요즘 대시보드" 스타일이다: 맨 위 블록은 채팅 응답과 똑같이 항목마다 3줄(이름·수치 / 12칸 막대, 넘으면 길어짐 / 퍼센트·남음)로 칼로리·단백질·탄수화물·지방과 초과·누적을 한 번에 보여준다. 그 아래는 어두운 면 카드, 얇은 경계선, 둥근 윗부분 막대 그래프, 부드러운 면적 선 그래프, 달력 히트맵. 색은 항목마다 고정(칼로리 초록 #4ade80, 단백질 노랑 #facc15, 탄수화물 청록 #22d3ee, 지방 보라 #c084fc, 초과 빨강 #ff5a5f). 글꼴은 Inter + Noto Sans KR. 이모지는 쓰지 않는다(채팅 응답은 기존 이모지 유지). 화면은 일간·주간·월간·추이 네 가지뿐이고, 체지방·연속 달성·예측 같은 추가 기능은 넣지 않는다(사용자 요청 시에만).
- 페이지는 `scripts/build_site.py`가 `data/log.json`에서 만든 일별 합계 `data.json`만 읽는다. 음식 이름이 든 `data/log.json`은 배포물(`_site/`)에 넣지 않는다.
- 데이터 입력은 평소대로 `data/log.json`, `docs/diet_log.md`만 갱신하고 푸시하면 된다. `.github/workflows/pages.yml`이 푸시마다 `data.json`을 다시 만들어 배포하므로 페이지는 1~2분 안에 자동으로 갱신된다. 별도 작업은 필요 없다.
- 집계 규칙(목표, 이월, 탄수화물 목표)을 바꾸면 `scripts/diet_core.py`의 상수·계산과 이 문서를 함께 고친다(사이트와 `diet.py`가 같은 코드를 쓴다).
- 오늘 진행 중인 날은 주간·월간·추이의 평균에서 제외하고 표시한다.
